# License change — Apache 2.0 → PolyForm Small Business 1.0.0

**Date:** 2026-08-19

## What changed

This repository's README previously stated **Apache 2.0**. It now carries the **PolyForm Small
Business License 1.0.0** with two irrevocable carve-outs. See [`LICENSE`](LICENSE).

This is a **restriction**, not a clarification, and it is recorded here rather than quietly
applied. Apache 2.0 is a permissive license; PolyForm is source-available with a commercial
threshold at $5M annual revenue.

## Who is affected

**Nobody, as far as we can determine.** At the time of the change this repository had:

- 0 releases
- 0 tags
- 0 forks

There is no published version that anyone could have taken under the previous terms. The change
was made before a v1.0 release specifically so that it would not break an existing user.

## If you did take a copy under Apache 2.0

Any copy obtained from this repository before 2026-08-19 remains available to you under Apache
2.0. **We do not attempt to retroactively restrict a grant already made** — an Apache 2.0 grant,
once given, is irrevocable for the version it was given on. Open an issue if you need that
confirmed in writing for your legal team and we will confirm it.

## Why the change

The Apache line was a placeholder from the first commit and was never a deliberate decision. The
deliberate decision was taken by Council vote on **2026-04-20**, which selected PolyForm Small
Business 1.0.0 and attached two irrevocable carve-outs:

- **Academic and research use** — free for teaching and research, no revenue limit.
- **Tribal sovereign entities** — federally recognized tribes, tribal enterprises and tribal
  governments, free **regardless of revenue**.

That vote was never applied to any repository until now, which is itself the reason this file
exists: a decision that is made and never lands is indistinguishable from one that was never made.

## The condition this file satisfies

The April 20 vote carried a dissent from the adversarial seat: *"License change is the highest-risk
breaking change. Current users must be notified. Note that v1.0 remains available under the prior
terms for anyone who needs it."*

That dissent was not overruled — it was turned into a requirement, and this document is it.
